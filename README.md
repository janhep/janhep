# Jan Heisig

**Computational Physicist | Numerical Modelling | Scientific Software Development**

I am a physicist with a PhD in theoretical particle physics and over 15 years of experience in mathematical modelling, numerical simulation and scientific software development.

My work spans particle physics, cosmology and astroparticle physics, with a particular focus on computational methods for complex physical systems, numerical algorithms, parameter inference and the interface between theoretical predictions and experimental observations.

### Selected scientific software projects

- **[BSFfast](https://github.com/bsffast/BSFfast)** — Co-developer of a Python package providing numerical results for bound-state effects in dark-matter calculations, based on earlier theoretical and computational research.

- **[MadDM](https://github.com/maddmhep/maddm)** — Contributor to a scientific software framework for dark-matter calculations, including particle interactions and predictions for experimental searches.

- **[SModelS](https://github.com/SModelS/smodels)** — Contributor to an established framework for interpreting searches for new particles at the Large Hadron Collider.

My scientific software work also includes numerical simulations, cosmic-ray transport calculations, statistical inference and machine-learning methods for computationally demanding physical models. Not all of these projects are hosted on GitHub.

### Current interests

Physics-based simulation, scientific computing, numerical methods, machine learning for physical systems, and the development of reliable computational tools for scientific and industrial applications.
